# band dots

This repository is the factory scaffold for the BAND Desktop workflow.

Important:
- The human does not write the final application code here.
- The BAND Desktop agents are expected to generate, test, and verify implementation work in the `stage-1/` area.
- This repository contains the planning, factory operating rules, and generic mandates required to start the project safely.

Structure:
- `FACTORY.md` — operation guide and factory playbook
- `mandates/` — generic role instructions for the agents
- `stage-1/` — where the installation, code, and Docker work will be generated
- `band-room-export-placeholder.md` — placeholder for a room export or summary
- `DISPATCH_PROMPT.md` — the direct prompt to paste into BAND Desktop
